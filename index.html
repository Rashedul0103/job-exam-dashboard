Cloud storage & account

One-time setup: create a Supabase project, run the SQL setup file supplied with this dashboard, then enter your Project URL and publishable key below. Your study records are stored in Supabase, not browser storage. Never enter a service-role or secret key here.

Remove all subjects, topics, study sessions and the active timer from your cloud account. A backup is downloaded before the reset.

Keep a recent backup before making major changes. Importing a file replaces the current cloud data after confirmation.
